# Workshop — LepKom Gunadarma

A collection of HTML workshop exercises from LepKom (Lembaga Komputer), Universitas Gunadarma. The files cover basic HTML page structure and HTML5 multimedia features — canvas drawing, video and audio playback.

## Contents

- `index.html` — main exercise page
- `kerangka.html` — basic HTML page structure (kerangka = framework/skeleton)
- `canvas.html` — drawing with the HTML5 `<canvas>` element
- `video.html` + `video.mp4` — embedding and playing video with the `<video>` element
- `horse.mp3` / `horse.ogg` — audio files used in the audio playback exercise

## Tech Stack

- HTML5 — page structure, `<canvas>`, `<video>` and `<audio>`
- Plain media files (MP4 video, MP3/OGG audio) — no frameworks or build step

## Getting Started

No installation or server is needed. Open any `.html` file directly in a web browser, for example `index.html`, to view the exercise.
